# ミチノート

バイクの旅を地図と写真に残すWebアプリのソースコードです。

## ソースコード

`michinote-source.zip` をダウンロードして展開すると、コード・画像・依存関係の定義・データベース定義を含むプロジェクト一式を取得できます。

- React / TypeScript / Vinext
- Leaflet地図、GPS記録、GPX取り込み、手動ルート記録
- 写真、走行履歴、アルバム、共有リンク
- Cloudflare Workers / D1 / R2

実際の利用者の写真・走行履歴・認証キーは含みません。

## 開発

Node.js 22.13以上を使用し、展開したディレクトリで `corepack pnpm install`、`corepack pnpm dev` を実行します。ホスティングと認証・D1・R2の設定は別途必要です。詳細はアーカイブ内のREADMEと設定ファイルを参照してください。

このリポジトリはソースのバックアップです。公開中のサイトとの自動同期・自動デプロイは設定されていません。
