# ミチノート（仮称）引き継ぎパッケージ

バイクで走った道が「自分だけの白地図」に残り、まだ走っていない道を次の冒険として提案するアプリの企画一式です。
企画書・仕様・設計と、そのまま開発に使えるコードの土台をまとめています。

> 作成日：2026年11月4日 / バージョン 0.1（企画・試作段階）

---

## まず触ってみる（3分）

`prototype/index.html` をブラウザで開いてください（ダブルクリックで開けます）。スマホ幅でも動きます。

- **マップ**：走った道だけが緑で残る白地図。「地図が育つ様子を再生」で成長を再生できます
- **記録**：地図のオレンジの点をタップして道をたどる、疑似的な走行記録
- **提案**：空き時間・気分・避けたい道を選ぶと、未走行の道を含むルートを3つ提案
- **招待状**：届いた招待状を「行きたい道」として保存する／自分の走行から招待状を作る
- **履歴**：愛車別の一覧と、1日分の冒険アルバム

地図は架空の地域で、GPSは使っていません。

## 中核ロジックの動作確認

Node.js 20 以上が必要です。

```bash
cd core
npm install
npm test        # 25件のテストが通ることを確認
npm run build   # dist/ に JavaScript と型定義が出力される
```

`core/` は画面や地図ライブラリに依存していないので、Webアプリ・スマホアプリのどちらを選んでもそのまま組み込めます。

## 引き継ぎ時のお願い

- 試作品のサンプル記録・招待状の「ソラ」は架空の例です。
- 企画スライドの画像は画面イメージ（コンセプト）で、実際の画面とは異なります。
- 権利まわり（アプリ名、スライド画像の扱い、引き継ぎの条件）は当事者どうしで確認してください。
